# Hardset 1.1

What a lifter notices. Nothing here changes how a set is logged, and nothing here is behind the paywall.

## Added

- Settings has a new page, "What Hardset won't say": the four claims the app refuses to make, each beside the rule that stops it.
- A movement's chart has a rep ladder: the heaviest working set you have done at each rep count from 1 to 12, on that machine. Rep counts you have never done are left out.
- A finished workout's receipt shows planned sets against working sets logged, one line per planned movement ("0 of 3 planned sets"). Counts only, no grade.
- Gyms and machines shows what each machine has been used for: last used, sessions, working sets and heaviest load.
- Every saved workout has a History button. It lists that workout's recent finished sessions, newest first, with the date, working sets, volume and what was done on each movement.
- The Library says how many working sets you have logged on a movement and when you last did it. Imported sets are counted apart.

## Changed

- A live movement card says when its "Last time" figures were done ("Last time 25 Oct · 2 weeks ago"). Figures borrowed from another machine carry the date in their note.
- The import preview names the span of workout dates in the file and how many are later than today.

## Fixed

- Nothing in this release is a bug fix.
