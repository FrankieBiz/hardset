## 1. Project Mission & Core Tenets

Hardset is a local-first, CloudKit-synced hypertrophy logger for intermediate and advanced lifters on iOS. It requires no accounts, contains zero social feeds, and refuses to prescribe black-box "AI coaching."

It exists to answer one question honestly, set after set:
***What did I actually do, on this machine, and what does that justify me doing next?***

### The Three Inflexible Commitments
1. **Calibrated Honesty**: The app states what it knows and what it does not. Every metric carries an explicit certainty and provenance source (`CertaintyBadge`). Missing data renders as *"unevaluated"* rather than an interpolated curve or a confident guess.
2. **Machine-Level Awareness**: Exercise load history is keyed to `exerciseID × machineID`. A 100 kg leg press on a 45° Cybex sled is not the same as 100 kg on a horizontal cable press. Hardset never silently copies load across distinct machines. Cross-machine substitutions must carry an explicit lower-certainty attribution badge.
3. **Gym-Floor Craft & Zero-Latency Speed**: Designed for someone with an elevated heart rate standing at a machine. One tap to log, prefilled from historical snapshots, micro-adjusted via inline steppers matching the machine's plate/stack increment. Zero database queries on the UI render loop.

### What the Product Refuses to Do
- Never guess a number or hide uncertainty behind a clean figure.
- Never flatten distinct physical machines into a generic movement string.
- Never lock basic logging, personal history, or raw CSV/JSON/SQLite data export behind a paywall.
- Never lose a logged set to memory pressure, app backgrounding, or iCloud sign-outs.
- Never build an in-app social network feed, follower graph, or influencer clutter.

## 3. Non-Negotiable Invariants (Never Break These)

1. **Duration is Derived, Never Stored**:
   - `SessionTimeline` holds two immutable timestamps (`startedAt`, `endedAt`). An active session's duration is `nil`, never a ticking integer. There is no `duration` column in SQLite.
2. **Rest is an Absolute Date, Never a Countdown**:
   - `RestTimerState` is modeled as an immutable target deadline (`Date`). "Both a deadline and a remainder" is unrepresentable. Ticking timers desync across app backgrounding, Focus modes, and device restarts; absolute target dates survive.
3. **Zero Database Work Per View Render**:
   - `PriorPerformanceSnapshot` is an immutable struct built once at session initialization. Set row rendering, steppers, and keyboard typing do zero SQL queries or disk I/O.
4. **Permanent, Additive-Only Database Schema**:
   - SQLite tables follow strict rules: never drop tables, never alter column nullability or defaults, never rename columns (`DECISIONS.md` §4).
   - `HardsetSyncDelegate.syncEngine(_:accountChanged:)` must remain explicitly implemented to prevent SQLiteData from wiping local data during iCloud account transitions.
5. **SessionCoordinator Write Ordering**:
   - A set row is marked logged *only after* the database write succeeds. Never optimistically mark a set logged in memory before persistence completes.
6. **Swift 6 Strict Concurrency**:
   - Compiled with `.swiftLanguageMode(.v6)` and `.enableUpcomingFeature("NonisolatedNonsendingByDefault")`.
   - Never bridge `Sendable` boundaries unsafely with `@unchecked Sendable` unless backed by a primary source decision.

## 4. UI Craft, Ergonomics & Design Language

- **Visual Point of View**: Governed by `DESIGN.md`. High visual restraint. The background is a calibrated deep dark palette (near-black charcoal `#0B0C0E` and `#14161B`).
- **Typography as Hero**: Tabular numbers (`.monospacedDigit()`) for weights, reps, and timers. Information density is high, like a cockpit or high-end mechanical instrument.
- **Gym-Floor Interaction**:
  - Sets prefill automatically from the last performance on that specific machine.
  - Set micro-adjustments happen via inline +/- steppers matching the machine's pin or plate stack increment (e.g. ±2.5 kg, ±5 kg). Keypad sheets are reserved only for large jumps.
  - Tapping a prefilled value replaces it on the first keystroke instead of appending.
